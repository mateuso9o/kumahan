# คุมอาหาร

แอปคุมอาหารและติดตามร่างกายสำหรับใช้ในบ้าน ตัวเลขทุกตัวมีที่มา และเป้าพลังงานปรับเองทุกสัปดาห์จากแนวโน้มน้ำหนักจริง

## ใช้งาน (ช่วงที่ 1)

1. **ตั้งโปรไฟล์** แต่ละคนในเครื่องของตัวเอง (ข้อมูลเก็บในมือถือเครื่องนั้น)
2. **ชั่งน้ำหนักทุกเช้า** ในแท็บ "ร่างกาย" หลังเข้าห้องน้ำ ก่อนกิน และวัดรอบเอวสัปดาห์ละครั้ง
3. **บันทึกอาหาร** ชั่งเป็นกรัม แล้วเลือกให้ตรงว่า *ดิบ* หรือ *สุก* (ข้าวสาร 100 g ≈ 365 kcal แต่ข้าวสุก 100 g ≈ 130 kcal)
4. กด **"วันนี้บันทึกครบแล้ว"** ทุกวันที่บันทึกครบ แอปใช้เฉพาะวันเหล่านี้คำนวณการเผาผลาญจริง
5. หน้า **วันนี้** แสดงธงโภชนาการของคุณ ว่าเหลืออะไรเท่าไหร่ และควรกินอะไรเพิ่ม กด "ที่มาของตัวเลข" เพื่อดูว่าแต่ละเป้ามาจากไหน

ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้น ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย (ช่วงที่ 3 จะเพิ่มการสำรองขึ้น cloud)

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest
npm run build    # dist/ สำหรับ deploy
node scripts/build-foods.ts <โฟลเดอร์ CSV ของ USDA SR Legacy>   # สร้าง src/data/foods.seed.json ใหม่
```

## ติดตั้งบนมือถือ

เปิด **https://mateuso9o.github.io/kumahan/** บนมือถือ แล้ว

- iPhone: Safari → แชร์ → "เพิ่มไปยังหน้าจอโฮม"
- Android: Chrome → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

ทุกครั้งที่ push เข้า `main` GitHub Actions จะรัน test, build และอัปเดตเว็บเอง (`.github/workflows/deploy.yml`)

## แหล่งข้อมูล

- ข้อมูลอาหาร: USDA FoodData Central, SR Legacy (public domain)
- ค่าแนะนำวิตามินและแร่ธาตุ: ปริมาณสารอาหารอ้างอิงที่ควรได้รับประจำวันสำหรับคนไทย พ.ศ. 2563 กรมอนามัย
- หลักการคำนวณ: `docs/2026-11-16-fitness-nutrition-app-design.md`

แอปนี้ให้ข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์
